# Passo a Passo: Criando um Projeto Simples em C# via CLI

Este guia mostra como criar, executar e editar um projeto C# simples usando o .NET CLI. Ideal para praticar e validar seus estudos de LINQ.

---

## 1. Pré-requisitos
- Ter o [.NET SDK](https://dotnet.microsoft.com/download) instalado (versão 6.0 ou superior recomendada).
- Verifique a instalação executando:

```bash
dotnet --version
```

---

## 2. Criar um Novo Projeto Console
No terminal, navegue até a pasta onde deseja criar o projeto e execute:

```bash
dotnet new console -n LINQ
```

Isso criará uma pasta chamada `LINQ` com um projeto console básico.

---

## 3. Navegar até o Projeto
```bash
cd LINQ
```

---

## 4. Estrutura Básica do Projeto
O arquivo principal será `Program.cs`. Edite esse arquivo para adicionar seus exemplos e testes de LINQ.

---

## 5. Executar o Projeto
Para compilar e rodar o projeto, use:

```bash
dotnet run
```

---

## 6. Dicas para Estudos
- Adicione exemplos de LINQ no `Program.cs` para praticar.
- Crie diferentes métodos para testar cada tópico do seu plano de estudo.
- Use o comando `dotnet run` sempre que quiser ver o resultado do seu código.
